# 🧹 账户组合账表清洗

把企业财务系统导出的序时账和科目余额表，整理成方便核对的借贷两列 Excel。原表里常把科目、银行账户、往来单位、项目和部门接在一串文字里。清洗后，每个科目使用一个明确的辅助核算维度。比如银行存款显示开户行和账号，应付账款显示供应商，管理费用显示归属部门。

## 🚀 把压缩包发给 Agent 就能开始

**把下载的「账户组合账表清洗技能.zip」原样发给 Agent。** 解压、检查运行环境、找安装位置和验证能否使用，都交给 Agent。

### 想先装好，以后再用

上传压缩包，再把下面这句话发给 Agent。

> 这是账户组合账表清洗技能。请你解压并阅读里面的使用要求，检查运行环境，按你支持的方式安装，然后验证能否运行。只有需要我授权或补充信息时再问我。完成后告诉我，下次怎么叫你使用这个技能。

### 现在就要清洗

把**压缩包和要处理的 Excel 源表**一起发给 Agent，再说这句话。

> 请解压这个技能包，用里面的程序自动识别并清洗我发的 Excel，整理成借贷两列。遇到影响结果的歧义先问我，处理完把结果和核对表发给我。

可以只发序时账或余额表，也可以两份一起发，文件名和顺序随意。两份一起核对时，请提供同一家公司、同一会计期间的资料。已经装好的 Agent 可以直接接收源表，告诉它使用「账户组合账表清洗」即可。

### Agent 会依次做什么

1. 解压技能包，检查本机能否运行。如果缺少必要组件，会按当前环境的权限处理，确实需要你授权时才来问。
2. 按你的用途安装技能或在本次任务里直接运行，再用程序预检源表。需要你选择时，会说明具体文件、工作表、行列位置和候选项。
3. 生成结果和清洗核对表。拿到结果后，先看核对表的「金额核对」，再看「待核记录」。

这套程序在 Windows 上运行。请选择能读取附件、解压文件并运行本机程序的 Agent。如果当前 Agent 权限不足，让它说明具体卡在哪一步。

## 📂 哪些原表可以处理

- 新版 Excel 工作簿可以直接读取。来源系统导出的旧版工作簿，先在 Excel 中另存为新版工作簿再交给 Agent。
- 表内需要有账户组合，也就是用点号分成十段的账户编码。序时账还需要日期、凭证号和本位币借贷金额。余额表还需要期初、发生额和期末金额。
- 表头前面可以有封面文字、标题、空行和单位说明。列可以换位置，表头可以有换行、同义写法、横向合并或纵向合并。
- 程序默认找每张工作表的前一百二十行，最多组合四层表头。表头实际更靠后时，告诉 Agent 大概在哪一行即可。一个文件里出现多张都能处理的候选工作表时，请告知实际要用哪张。
- 余额表的期初、期末可以是带正负号的净额，也可以是分别列出的借方和贷方。源表同时提供两种写法时，Agent 会先核对要用哪组金额。

## 🔎 程序是怎么清洗的

### 先找表，再找列

程序看表里的列名和表头结构，自动判断文件属于序时账还是余额表。它会还原合并表头的上下关系。例如「本位币」跨着下面的「借方」和「贷方」两列，即使同一张表另有原币列，也能依照上层标题定位本位币金额。

### 每个科目只选一种辅助核算

| 科目 | 结果里显示什么 | 取值做法 |
|---|---|---|
| 银行存款 | 开户行和账号 | 从账户组合的子科目段取 |
| 应收、应付、预付、预收等往来科目 | 往来单位或个人 | 从往来段取 |
| 开发成本、房产销售收入及成本 | 开发项目 | 从项目段取 |
| 应付职工薪酬、管理费用明细 | 归属部门 | 从部门段取 |
| 固定资产、累计折旧 | 资产类别 | 从科目名称取，例如「运输设备」 |
| 分税率的增值税进项税额 | 税率档 | 从科目名称取，例如百分之十三 |
| 长期借款本金 | 贷款银行 | 取本科目往来段登记的贷款行全称和编码 |
| 应付长期借款利息 | 贷款银行 | 按公司和合同编码匹配本金，唯一匹配时带出贷款行 |

技能带有三百零一个科目的现成规则。新增科目也会先按科目性质检查能否适用已有规则。比如名称清楚写着「固定资产－运输设备」，可以按运输设备归类。遇到名称含义不够明确的科目，Agent 会列出来请你选维度。

### 序时账逐笔保留，余额表按维度归并

序时账的每条原分录仍占一行，日期、凭证号和摘要随分录保存。借方、贷方分别写入，原表里的红字仍在原方向上显示为负数。

余额表按公司、科目和所选辅助项目汇总。同一个账号拆成几行、各行只是在往来对象上不同，清洗后可以合成同一个银行账户。期初、借方发生额、贷方发生额和期末分别相加。模板中的期初和期末沿用带符号净额，填在各自的借方余额列。借方余额为正，贷方余额为负，旁边的贷方余额列留空。重分类科目保留原编码。

### 最后回读核对金额

程序会算出原表金额和结果金额，再打开写好的文件逐行核对。两张源表同时提供时，还会按科目及辅助项目比较借贷发生额。原始账套或重分类口径有差异时，源表之间可能有差额，核对表会保留差额和涉及科目。

## 📦 会拿到哪些文件

| 文件 | 怎么用 |
|---|---|
| 序时账-借贷两列.xlsx | 查单笔分录、凭证号和借贷金额 |
| 余额表-借贷两列.xlsx | 看每个科目及辅助项目的期初、发生额和期末 |
| 清洗核对.xlsx | 看读到了哪个工作表、金额是否一致、有哪些待核项，以及具体来自原表哪一行 |

只提供其中一种源表时，收到该种结果和清洗核对表。每次运行会生成一个新结果文件夹，旧结果和原始账表不会被覆盖。

## 🛠️ Agent 问我时，我该怎么回答

- **同名列或多张工作表。** 告诉 Agent 哪张工作表、哪一列是你要出表的口径。例如「用科目明细页的 B 列作借方」。程序可以按确认的列继续，无须手动改原表。
- **新科目该取什么。** 用日常业务语言说明，例如「这个科目按楼盘项目归集」。Agent 会把确认内容作为本次规则再预检。
- **原表没有客户或银行。** 已有明确取值规则的记录可继续清洗。缺客户标为「往来未记录」，利息不能唯一匹配贷款行时标为「贷款银行待核」。金额及原始行位置保留。有可靠客户明细或贷款资料时，可以交给 Agent 核对。
- **公式没有保存结果。** 请在 Excel 中打开对应源表，重新计算并另存一份，再提供新文件。Agent 报出的单元格就是需要检查的位置。
- **金额单位或精度不清楚。** 先确认源表是元还是万元，以及金额实际保留几位小数。Agent 会按你确认的口径处理。
- **跨表有差额。** 在核对表看「金额核对」和「跨表科目差异」。先看每张表清洗前后差额是不是零，再检查两份源表的账套、期间和重分类范围是否一致。
